# 💧 EcoXAI 2.0
### Explainable IoT Water Intelligence for AI Data Centres

**EcoXAI 2.0 aims to help users understand cooling-water demand in AI data centres and identify operating conditions that may need attention.**

Its key innovation is simple: **don't just show a prediction—explain which factors influenced it and what to investigate next.**

## 🌱 The Problem

AI data centres use electricity and generate heat. Depending on the cooling system, keeping them cool may also require water. Understanding which operating conditions affect resource demand can be challenging.

## 💡 Our Solution

EcoXAI 2.0 is designed to bring resource indicators and understandable explanations into one dashboard.

### Key Features

- 💧 **Water Intelligence:** Explore water-use indicators.
- 📊 **Resource Dashboard:** View energy, water, carbon, and performance indicators where data is available.
- 🚨 **Fix First:** Highlight conditions that may need investigation.
- 🧠 **Explainable AI:** Use SHAP to explain which inputs influence a prediction once integrated.
- 🔄 **What-If Analysis:** Compare different operating scenarios.
- 🌐 **IoT Integration:** Designed for future connection to real sensor readings.

## ✨ What Makes EcoXAI 2.0 Different?

Unlike a dashboard that only displays numbers, EcoXAI 2.0 aims to explain **why a prediction was made** and help users understand what to check next.

## ⚙️ Technology Stack

- Python
- Streamlit
- Pandas and NumPy
- Plotly
- Scikit-learn / Random Forest
- SHAP
- IoT sensors (planned integration)

## 📌 Current Project Status

The current dashboard is a prototype. Its monitoring feed and example calculations are simulated. The trained model, genuine SHAP explanations, and physical IoT sensors must be connected and tested before they can be claimed as fully operational.

## 🚀 Future Improvements

- Connect the trained machine-learning model.
- Integrate genuine SHAP explanations.
- Add and test real IoT sensor readings.
- Validate predictions using unseen test data.
- Improve recommendations using verified operating limits.

## 🌍 Our Vision

To make AI data centres more sustainable by making water-resource information easier to understand and act upon.

**Estimate clearly. Explain the result. Help users decide what to check next.**
